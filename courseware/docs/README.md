# GitHub Copilot as a Coding-Agent Harness

Reference documentation, organized into **modules** that follow the
[course outline](../outline/pdf/GitHubCopilotAsACodingAgentHarness_Outline.pdf). Each module is a folder,
and the numbered chapters inside it are meant to be read in order. In class, every module is taught as a
short lesson, a live demo, and a hands-on activity; these chapters are the reference to come back to
afterward.

> Modules `01`–`04` map one-to-one to the outline's Modules 1–4. Module `05` is the outline's
> Conclusion. Examples use the course's [sample apps](../samples/README.md), mostly the library app
> the instructor demos on, in both .NET and Java.

> **Copilot changes weekly.** These chapters were checked against the product in November 2026. Where a
> button label or a default matters to you, confirm it in the build you're using.
